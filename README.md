# ReverseHub AI

## Project Overview

ReverseHub AI is a reverse marketplace application designed for modern procurement workflows.

The platform allows buyers to publish product or service requirements, suppliers to discover relevant opportunities and submit competitive quotations, and buyers to compare available offers before selecting a supplier.

The application also provides supplier management, order tracking, messaging, notifications, analytics, and administrative workflows for managing users, supplier verification, fraud alerts, and platform reports. 

---

## Key Features

### Buyer Workspace

- Create and publish procurement requirements
- Specify product/service details
- Set quantity, budget, location, and delivery requirements
- View submitted quotations
- Compare supplier offers
- Review supplier information
- Accept a quotation
- Create and track orders
- Communicate with suppliers
- View notifications and analytics

### Supplier Workspace

- View available procurement requirements
- Discover relevant buyer requests
- Submit quotations
- Specify pricing, GST, delivery time, warranty, and notes
- Manage submitted quotations
- View accepted deals
- Communicate with buyers
- Monitor order progress

### Quote Management

- RFQ-based quotation workflow
- Supplier quotation submission
- Quote comparison
- Price comparison
- Delivery comparison
- Warranty comparison
- Supplier rating and experience
- Risk indicators
- AI-assisted/rule-based quote scoring
- Quote acceptance workflow

### Order Management

- Automatic order creation after quote acceptance
- Order ID generation
- Supplier and buyer association
- Order status tracking
- Progress tracking
- Delivery timeline
- Invoice generation
- Order notifications
- Order lifecycle management
